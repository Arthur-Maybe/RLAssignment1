# Reinforcement Learning Assignment 1

# Project Structure
* robot_arm_env.py: Environment class implementation
* random_agent.py: Runner script executing random policies across test episodes

# Installation and Setup
Create and activate python venv

Run 
    pip install -r requirement.txt
to install the core required dependencies

# Execution
Run
    python random_agent.py
